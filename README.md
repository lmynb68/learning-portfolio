# learning-portfolio

个人学习作品集：STM32、FreeRTOS、控制系统、硬件设计、网页实践，以及 Obsidian 学习笔记。

## 使用

打开 index.html 浏览作品集；打开 notes.html 阅读笔记。无需安装依赖。

## 笔记

共 32 篇：STM32 16 篇、FreeRTOS 6 篇、Linux 10 篇。支持分类、全文搜索、笔记内部链接和 Markdown 下载。截图使用适合网页浏览的 WebP 副本。原始 Obsidian 笔记库未修改。课件保留名称引用，不收录原课件文件。

笔记属于学习过程记录，未逐条技术校核。第三方项目明确标注为开源阅读参考，不代表个人原创或已完成硬件验证。

## 文件

- projects.js：作品集条目。
- notes-data.js：在线笔记内容。
- notes/raw/：可下载的 Markdown。
- assets/notes/：笔记图片。
- notes-app.js、notes.css：笔记阅读交互与样式。

笔记从本地导出维护，网站不能自动同步 Obsidian 的后续修改。
